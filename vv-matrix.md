Each Item carries its milestone tag `[Mx]`. CI fails the milestone gate
(`cargo xtask lint`'s vv-matrix gate) if a **soundness-critical** row (marked ★) whose
milestone has **landed** (`[M0]`, `[M1]`, `[M2]`, `[M3a]`, `[M3c]`, `[M3d]`, `[M3e]`, `[AUTH.1]`, `[AUTH.2]`, `[AUTH.3]`) has empty {Kani ∨ Lean ∨ runtime-checked-hypothesis}.

above is the authority and must track `xtask`'s `LANDED`.

matched a mid-cell word instead of the ★ Item and passed vacuously — fixed with the M3d landing.

with `M` and hold alphanumerics only, so every **dotted** tag — every `[AUTH.x]` row — was skipped
