# certify-check — Lean 4 extraction target

The deductive-verification surface for the Kirigami kernel. Hosts:
- the **hand-written Lean specs** of the `certify-core` checkers (each spec *is* the formalization of its certificate definition — `vv-guide §4`), and
- the **hax / Aeneas lifted models** of those checkers (Rust → Lean, always; there is no Lean → Rust codegen).

A `lake` project, **not** a cargo crate — hence it lives outside the cargo workspace.

## Pins (locked by the vv-guide §7 spike — `docs/spike-extraction-report.md`)

- **Lean `v4.31.0`** (`lean-toolchain`) — matches the Aeneas Lean backend's toolchain.
- **Mathlib `v4.31.0`** and the **Aeneas Lean library** (`AeneasVerif/aeneas @ 3a8586fa`, `backends/lean`) via `lakefile.toml` (both committed in `lake-manifest.json`). The two agree on Mathlib, so lake resolves one shared copy.

## Layout

- `CertifyCheck/SignVariations.lean` — the sign-variation counter's **spec** (`signVariations`) + a transcription of the streaming Rust algorithm (`signVariationsImp`) + their equivalence (`signVariationsImp_eq_signVariations`, **axiom-clean**). Core Lean, no Mathlib.
- `CertifyCheck/SturmChecker.lean` — the Sturm hypothesis-checker: `IsSturmChainData` (what `verify_chain` checks), `variationAt` (reuses `signVariations`), Sturm's theorem as the **single cited axiom** `sturm_root_count` (Mathlib has Descartes, not Sturm), and `verify_chain_sound`.
- `CertifyCheck/LiftedAeneas.lean` + `Lattice/` — the Aeneas-lifted model of `crates/lattice`'s `sturm::sign_variations` (generated by charon→aeneas from the real crate), integrated and shown `sorry`-free; the loop-invariant refinement is designed (report §5) and gated to Phase 5.

`proofs/ledger.md` records the Sturm theorem (citation, hypotheses-checked-at-runtime vs structural, the axiom in the checker's footprint).

## Build (the CI "Lean proof surface" step)

Requires `elan` + `lake` (the default dev flake). On darwin, unset `DEVELOPER_DIR`/`SDKROOT` (the nix `xcbuild` `xcrun` rejects the SDK-only path, breaking `git`-in-lake):

```
cd certify-check
unset DEVELOPER_DIR SDKROOT   # darwin only
lake exe cache get            # Mathlib prebuilt oleans
lake build
```

## Re-generating a lifted model

Needs the hax/charon/aeneas **binaries** — `nix develop .#extraction`:

```
cd crates/lattice
charon cargo --preset=aeneas --start-from crate::sturm::sign_variations --dest <tmp>
aeneas -backend lean <tmp>/lattice.llbc -dest <tmp>/out -split-files
# place <tmp>/out/{Types,Funs}.lean under certify-check/Lattice/
```
